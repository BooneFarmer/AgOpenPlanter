# AgOpenPlanter
Experimental open source planter monitor app for Wndows.  To run on top of AgOpenGPS autosteer app to dispaly Ag planter performance.  This is an exercise in precission farming applications for programming students. Not intended for actual use, so don't try this on real live equipment asd it may not give accurate information. 

Designed to communicate with a microprocessor based control box programmed to listen to planter's seed sensors and communicate to the Window app via UDP.
